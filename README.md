## 🚀 Быстрый старт

### Локальная разработка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd timeland-website
```

2. Откройте `index.html` в браузере или используйте локальный сервер:
```bash
# Используя Python
python -m http.server 8000

# Используя Node.js (http-server)
npx http-server

# Используя PHP
php -S localhost:8000
```

3. Откройте браузер и перейдите по адресу `http://localhost:8000`

## 🔧 Кастомизация

### Изменение цветов
Отредактируйте CSS переменные в файле `styles.css`:
```css
:root {
    --black: #1a1a1a;
    --dark: #0a0a0a;
    --gold: #d4af37;
    --gold-light: #f4d03f;
    --gold-dark: #c9a044;
}
```

### Изменение контента
Отредактируйте текст в файле `index.html`

### Добавление новых секций
1. Добавьте HTML разметку в `index.html`
2. Добавьте стили в `styles.css`
3. При необходимости добавьте функционал в `script.js`
